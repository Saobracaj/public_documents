# Saobraćaj — документи / documents

Правни документи апликације [Saobraćaj](https://saobracaj.gleb.at) — тренажера за
полагање теоријског дела возачког испита у Републици Србији.
Историја измена сваког документа доступна је у
[репозиторијуму на GitHub-у](https://github.com/Saobracaj/public_documents/commits/main).

Документи ће бити објављени овде након повезивања домена; до тада погледајте
[изворне markdown фајлове](https://github.com/Saobracaj/public_documents).
